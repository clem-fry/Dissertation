## Engineering Turing Patterns for Spatial Organisation in Swarm Robotics

This was my dissertation for MSc Robotics at the University of Bristol. 

:trophy: Winner of *Most Accomplished Project* Award

I created a control system for patterning a multi-agent system with a desired spatio-frequency, regardless of changes to the topography of the swarm.

![alt text](https://github.com/clem-fry/Dissertation/blob/main/media/turing_pattern.png)

# The Project Achieved the Following:

1. Developing a systematic method for designing reaction–diffusion parameters that influenced the resulting spatial pattern. Parameters were filtered using linear stability conditions and desired characteristics.

![alt text](https://github.com/clem-fry/Dissertation/blob/main/media/dispersion-simulation.png)

2. Quantitatively evaluated the emergent patterns using wavelength as a metric to link abstract network dynamics with visible spatial outcomes in the swarm.

3. Demonstrated that parameter optimisation can effectively control a physical swarm of Kilobot robots. This includes verifying that the wavelength–mode relationship holds both in static-grid formations and following dynamic motion, even under high agent heterogeneity.

![alt text](https://github.com/clem-fry/Dissertation/blob/main/media/kilobot-grid-layout.png)
